# TESI2105_Programa_Evolutivo_Yadiel_Rivera
Proyecto final TES2105
Nombre de programa: Programa de Regidtro de Horas de Trabajo

Problema que atiende:
Permite calcular el dinero ganado durante la semana, dependiendo de las horas y de los trabajadores.

Usuario Principal: 
Un empleado o supervisor que necesita calcular rápidamente el pago semanal de una persona que trabaja por hora, incluyendo el pago de tiempo extra cuando aplica.

Descripcion:
Este programa permite al usuario calcular la paga total semanal de los empleados al ingresar el nombre del empleado, las horas trabajadas y el pago por hora. En la versión 2.0 el programa evolucionó para registrar las horas trabajadas día por día durante una semana completa mediante un ciclo, y para determinar automáticamente si el empleado trabajó horas extra mediante una estructura de decisión, pagando esas horas a una tarifa mayor.
